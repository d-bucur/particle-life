Particle life cluster simulator

See it in action: https://sirdorius.itch.io/particle-life

## Dev
Last ran with `odin version dev-2025-08-nightly`. Does not work with newer Odin versions

Press F5 in VSCode to run. Or run build scripts and executable will be in `build/` folder

Note: Project is configured to work on linux and vscode. Scripts for win and sublime are kept around from the template but might be out of date
